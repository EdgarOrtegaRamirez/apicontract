# APIContract — OpenAPI/Swagger API Contract Validation Toolkit

A comprehensive CLI toolkit for validating, diffing, and generating code from OpenAPI/Swagger specifications.

## Features

- **Validate** — Check OpenAPI 3.x and Swagger 2.x specs for structural correctness, required fields, and path parameter consistency
- **Check** — Send HTTP requests to a running API and validate responses against the contract (status codes, headers, JSON schema)
- **Diff** — Compare two OpenAPI specifications and detect breaking changes, added/removed endpoints, and schema modifications
- **Generate** — Auto-generate client stubs in Go, Python, or TypeScript from OpenAPI specs
- **Info** — Display spec metadata, endpoint statistics, and method breakdowns
- **Schema Validation** — Full JSON Schema validator for request/response body validation (strings, numbers, objects, arrays, enums)

## Quick Start

```bash
# Install
go install github.com/EdgarOrtegaRamirez/apicontract/cmd/apicontract@latest

# Validate a spec
apicontract validate swagger.yaml

# Show spec info
apicontract info swagger.yaml

# Generate Go client stubs
apicontract generate swagger.yaml -f go

# Generate Python client stubs
apicontract generate swagger.yaml -f python

# Check endpoints against a running API
apicontract check swagger.yaml http://localhost:8080

# Diff two specs
apicontract diff spec-v1.yaml spec-v2.yaml
```

## Example: Generate Client Code

```bash
$ apicontract generate petstore.yaml -f go
// Generated client stub for Pet Store API v1.0.0
// This file was auto-generated by apicontract

package client

import (
	"net/http"
	"time"
)

type Client struct {
	BaseURL string
	HTTPClient *http.Client
}

func NewClient(baseURL string) *Client {
	return &Client{
		BaseURL:    baseURL,
		HTTPClient: &http.Client{Timeout: 30 * time.Second},
	}
}
// ... more methods
```

## CLI Reference

| Command | Description |
|---------|-------------|
| `validate <spec>` | Validate spec for structural issues |
| `info <spec>` | Show spec metadata and statistics |
| `check <spec> <url>` | Test endpoints against running API |
| `diff <old> <new>` | Compare two specs, show changes |
| `generate <spec> -f <fmt>` | Generate client stubs (go/python/typescript) |

## Architecture

```
apicontract/
├── cmd/apicontract/       # CLI entry point (Cobra)
├── internal/
│   ├── parser/            # OpenAPI/Swagger spec parser (YAML + JSON)
│   ├── validator/         # Contract validation engine + JSON Schema validator
│   ├── differ/            # API diff engine (breaking change detection)
│   ├── generator/         # Client code generator (Go/Python/TS)
│   └── cli/               # CLI command definitions
├── tests/                  # Integration tests
└── .github/workflows/     # CI configuration
```

### Parser
- Loads OpenAPI 3.x and Swagger 2.x specs (YAML and JSON)
- Recursive descent path-item parser extracts HTTP operations
- Path parameter extraction with `{param}` and `:param` syntax support

### Validator
- Structural validation: required fields, path parameter definitions
- Runtime validation: status codes, headers, JSON schema
- JSON Schema subset: object, array, string, number, boolean with minLength/maxLength, min/max, enum

### Differ
- Compares two specs endpoint by endpoint
- Detects: added/removed endpoints, parameter changes, response changes, schema modifications
- Severity classification: breaking vs non-breaking changes
- Sorted output: breaking changes first
